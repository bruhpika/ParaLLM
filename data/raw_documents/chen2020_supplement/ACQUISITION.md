# Chen2020 supplementary data (not redistributed)

The supplementary PDF for Chen et al., "Development of Experimental Techniques
for Parameterization of Multi-scale Lithium-ion Battery Models", J.
Electrochem. Soc. 167 080534 (2020), DOI 10.1149/1945-7111/ab9050, is **not
redistributed** in this repository because redistribution permission was not
verified (ECS copyright). Obtain it from the publisher's supplementary
materials for DOI 10.1149/1945-7111/ab9050 and place it locally as
`JES_167_8_080534_suppdata.pdf` in this directory, then regenerate the
derived text/segments via `scripts/p4/ingest_supplement.py` (or the P3
ingest path) if you need to reproduce P4/P5 supplement-derived items.

The benchmark fixture items and recorded extraction results derived from it
remain in-repo as research artifacts with provenance; the source file itself
is excluded from distribution.
