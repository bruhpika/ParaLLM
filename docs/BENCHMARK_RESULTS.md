# Benchmark Results (P2–P5)

Responsible disclosure of what was measured, on which fixture, and what it does
**not** establish. No independent experimental validation is claimed.

## 1. Synthetic parameter recovery (P2) — *not experimental validation*

PyBOP-based bounded fitting recovers parameters from **seeded synthetic** data
generated by the Chen2020 DFN forward model (`calibration/synthetic`,
`calibration/fitting`; configs `configs/p2/recovery_*.yaml`; outputs
`results/p2/`, `benchmarks/parameter_recovery/`). This exercises the estimation
and reporting machinery and sensitivity/identifiability analysis
(`docs/IDENTIFIABILITY_STUDY.md`, `results/p2/identifiability_*`,
`diffusivity_feasibility/`).

**Disclosure:** synthetic parameter recovery demonstrates pipeline correctness on
known ground truth; it **is not** experimental validation, does **not** prove
identifiability on real cells, and optimization success ≠ identifiability.
Calibration and validation data must remain disjoint.

## 2. Literature extraction benchmark v3 (P5) — 37 items, 3 repeats/arm

- **Fixture:** `data/eval/extraction_benchmark_v3.jsonl` — **37 items** = v2 (20)
  + 17, over **6 documents** (chen2020 article + supplement, PyBaMM parameter-sets
  docs, Laue 2021, Dessantis 2023, Goussian 2024). Splits **8 dev / 29 eval**;
  tiers same-doc-dev/heldout, cross-document, other-cell-family; **6 abstention**
  items. v2 items preserved; v3 only (no P4/v2 aggregates mixed). See
  `docs/P5_BENCHMARK_EXPANSION.md`.
- **Protocol:** 4 conditions (retrieval_strict, no_retrieval_memory,
  no_retrieval_strict, offline reference), **3 repeated runs per LLM arm**
  (offline n=1), same model/task/schema/frozen P4 rubric, temp 0,
  `mimo-v2.6-flash` via OpenAI-compatible endpoint. **Raw model outputs preserved
  verbatim** per repeat. Transient transport failures (2 retrieval repeats)
  documented and resumed without overwriting originals
  (`raw_outputs_retrieval_strict_r0.partial_pre_incompleteread.jsonl`).
  Artifacts: `results/p5/benchmark_v3/` (`report_*`, `aggregate_*`,
  `consistency_*`, `summary.md`).
- **Metrics (frozen P4 semantics):** parameter identification, value extraction,
  unit accuracy, provenance, condition completeness, qualifier classification,
  abstention accuracy, false extraction rate (value/unit/provenance/condition/
  qualifier computed over matched candidates).

### Interpretation (disclosed)

- **Retrieval is required for grounded extraction.** Strict no-evidence abstains
  on every item (3/3 repeats). Retrieval achieves high value/provenance with
  **zero false extractions** and perfect abstention.
- **Memory-without-evidence is unsafe as a source of parameters:** zero
  provenance, **0.275 false-extraction rate**, abstention accuracy 0.333 (fails
  to abstain on abstention items) — i.e. unsupported/unverifiable claims. Its
  higher condition score reflects ungrounded filling, not evidence.
- **Experimental-condition extraction is weak (explicitly disclosed).** Under
  retrieval, condition completeness is **0.116 (all) / 0.035 (eval)** — the main
  residual weakness (many passages state values but not temperature+cell_config;
  inference is forbidden by rule 6). Qualifier improves over P4 but remains
  imperfect (0.741 all / 0.776 eval).
- **Run-to-run variance exists** at temp 0 (15 metric-variances across 13 items
  under retrieval; larger under memory). Per-item: `consistency_*.json`.
  Consistently weak: E12-j0-pos-eis, P5-L3/L4/L6 table/scale parsing,
  V5-reaction-rates, E4-supp-sep-porosity.

## 3. Real experimental validation — **not claimed**

No independent experimental validation is reported. The in-repo LG M50 sample is
a C/10 pseudo-OCV charge at ~32.3 °C with **license UNRESOLVED** and is
ineligible for Chen2020-aligned 25 °C multi-rate discharge validation;
Chen2020 experimental traces are **UNRESOLVED** (T5). A real-data fitting
experiment is **designed but not run** (T6, disjoint calibration/validation,
active-material volume fractions primary). See `docs/P5_DATA_ACQUISITION.md`,
`docs/P5_REAL_DATA_EXPERIMENT_DESIGN.md`, `docs/SCIENTIFIC_LIMITATIONS.md`.
